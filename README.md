# Flutter Portfolio App

A Flutter based portfolio application built to showcase real world projects, technical decisions, and production like app flows. This app is designed as an interactive portfolio rather than a static website.

## Overview

This project demonstrates how a Flutter application can be structured and presented in a realistic and professional way. It focuses on clean UI, thoughtful UX decisions, clear project explanations, authentication demos, and a mobile first experience.

Users can explore all projects without login. Signing in is optional and is used only to demonstrate protected screens and authentication based UI behavior.

## Platform Focus

Primary Platform: Android APK  
Secondary Platform: Flutter Web optional preview

This project is optimized for mobile experience. For the best and most accurate UI representation, the Android APK is recommended.

## Authentication Note

Authentication is used only to demonstrate protected screens authentication based UI behavior and user specific demo features. This app is not intended to function as a full multi user production system.

## Why This Project

Instead of a static portfolio website this app was built to reflect real mobile app behavior showcase engineering thinking demonstrate production style structure and provide a better evaluation experience for recruiters and reviewers.
